# Microsoft Fabric + Foundry AI Practice Guide

This guide will help you practice using Microsoft Fabric and Foundry AI before your interview.

## Step 1: Set Up Microsoft Fabric Workspace
1. Go to [Microsoft Fabric portal](https://app.fabric.microsoft.com/).
2. Create a new workspace (requires Fabric or Power BI license).
3. In the workspace, create a new Lakehouse or Data Engineering experience.

## Step 2: Upload Sample Data
1. Use the Lakehouse 'Files' or 'Tables' section to upload sample data (CSV, JSON, etc.).
2. You can use the sample data in `sample_data/` from this repo.

## Step 3: Create a Notebook
1. In Fabric, create a new Notebook (PySpark or SQL).
2. Load your sample data and perform basic data engineering tasks (ETL, transformations).

## Step 4: Integrate with Foundry AI
1. If you have access to Microsoft AI Foundry, connect your Fabric workspace to Foundry.
2. Use the Foundry UI to create an agent or model.
3. Experiment with agent workflows, prompt engineering, and model evaluation.

## Step 5: Practice AI Workflows
- Try building a simple data pipeline: ingest data, clean it, and run a basic ML model.
- Use notebooks to call Foundry AI agents (if available) or use built-in Spark ML.

## Step 6: Document Your Work
- Use this folder to save your local notebooks, scripts, and notes.
- Document your learnings and questions for the interview.
